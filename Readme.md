# Telegram Chat History To TXT Converter

Простой инструмент для объединения и очистки экспортированной истории чатов из Telegram (формат HTML) в один структурированный текстовый файл (.txt).

## 📌 Что делает этот скрипт?

Если вы экспортируете чат из Telegram, он часто разбивается на десятки или сотни HTML-файлов с кучей лишнего кода, служебных сообщений и медиа-контейнеров.

Этот скрипт:

- Собирает все части чата (messages.html, messages2.html и т.д.) в правильном хронологическом порядке
- Очищает текст от HTML-тегов, лишних переносов и «мусора»
- Форматирует каждое сообщение в строгий вид: "Имя", "Дата", "Время": "Текст сообщения"
- Сохраняет результат в один компактный файл `all_messages_combined.txt`

## 🛠️ Требования

- Windows (для использования .bat файла)
- Python 3.x (установить с [python.org](https://www.python.org))

## 🚀 Как пользоваться

### Шаг 1: Экспорт чата из Telegram

1. Откройте Telegram Desktop
2. Перейдите в нужный чат → Настройки (три точки) → Экспорт истории чата
3. В настройках экспорта снимите галочки со всех медиафайлов (фото, видео, голосовые и т.д.) — скрипту нужен только текст
4. Выберите формат: **HTML**
5. Нажмите «Экспортировать»

### Шаг 2: Подготовка файлов

1. После завершения экспорта откройте папку, куда Telegram сохранил данные
2. Скопируйте файлы `run_convert.bat` и `convert.py` в эту папку (туда, где лежат файлы `messages.html`)

### Шаг 3: Конвертация

1. Просто запустите файл `run_convert.bat` двойным кликом
2. Скрипт сам проверит наличие Python, установит нужную библиотеку (BeautifulSoup4) и обработает все сообщения
3. По завершении в папке появится файл `all_messages_combined.txt`

## 📝 Формат вывода

После обработки каждое сообщение будет выглядеть так:

```
"Иван Иванов", "09.03.2023", "21:37": "Привет! Как дела?"
"User123", "09.03.2023", "21:38": "Всё отлично, скрипт работает."
```

## ⚠️ Важные примечания

- Служебные сообщения (изменение фото группы, закрепленные сообщения, уведомления о входе/выходе) автоматически игнорируются
- Переносы строк внутри одного сообщения заменяются пробелами, чтобы каждое сообщение занимало ровно одну строку. Это удобно для последующего анализа данных или поиска
- Если у сообщения нет имени отправителя (например, в «склеенных» сообщениях от одного человека), скрипт автоматически подставляет имя последнего известного отправителя
